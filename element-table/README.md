# ธาตุ & จาน — Element Table (clone)

เปิดโดยรันเซิร์ฟเวอร์ static ในโฟลเดอร์นี้ เช่น `python3 -m http.server 8000` แล้วเข้า http://localhost:8000
(เปิดไฟล์ index.html ตรง ๆ ผ่าน file:// ก็ใช้ได้เกือบทั้งหมด แต่แนะนำให้ใช้เซิร์ฟเวอร์)

## ไฟล์
- index.html, style.css, app.js, mix-core.js, favorites.js, lunar.js — จากไฟล์ต้นฉบับที่คุณส่งมา (แก้ app.js ให้ใช้รูปในเครื่อง)
- api-shim.js — ของใหม่ แทน backend `/api/*` เดิม เก็บร้านประจำใน localStorage
- img/ — รูปประกอบ

## ที่ต่างจากเว็บเดิม
- ไม่มีระบบค้น/รีเสิร์ช 7-Eleven อัตโนมัติ (ปุ่ม "อัปเดตเมนู" แค่อัปเดตเวลาตรวจ) ร้าน 7-11 เริ่มต้นมี 4 เมนูที่เห็นในหน้า ไม่ใช่ 54 เมนู
- ร้านประจำไม่ซิงก์ข้ามอุปกรณ์ เพราะเก็บในเบราว์เซอร์นี้เท่านั้น
- แก้บั๊กใน HTML ที่บันทึกมา: ตัวเลือก "หลีกเลี่ยงถั่วเหลือง" และ "ไม้" ในโปรไฟล์ไม่มีแท็ก <option>
- ไม่มีวันเกิดเริ่มต้น: ผู้ใช้ใหม่เห็น "โปรไฟล์ตัวอย่าง" จนกว่าจะกรอกวันเกิดในโปรไฟล์
