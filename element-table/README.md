# ธาตุ & จาน — Element Table (clone)

## วิธีรัน
```bash
python3 server.py
```
แล้วเปิด http://localhost:8000 (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม) เซิร์ฟเวอร์นี้เปิดระบบค้นเมนูร้านประจำอัตโนมัติ และเก็บข้อมูลไว้ที่ `data/shops.json`

ถ้าเปิดแบบ static (`python3 -m http.server` หรือหน้า Artifact) แอปยังใช้ได้ แต่ร้านประจำจะเก็บในเบราว์เซอร์ และต้องใส่เมนูเอง

## ระบบค้นเมนูอัตโนมัติ (server.py)
- ใส่ลิงก์หน้าเมนูของร้าน ระบบอ่านข้อมูล schema.org (Menu / MenuItem / Product) และไล่อ่านหน้าสินค้าในแค็ตตาล็อกเดียวกัน (สูงสุด 40 หน้าต่อชั้น)
- ร้านชื่อ 7-11 / เซเว่น อ่านแค็ตตาล็อก https://www.7eleven.co.th/new-product (ข้อมูลสินค้าใน `__NEXT_DATA__` ของหน้า) ได้ชื่อ ราคา คำอธิบาย และลิงก์สินค้า 58 รายการ (ทดสอบกับเว็บจริงเมื่อ 13 พ.ย. 2569)
- ตรวจซ้ำทุก 6 ชั่วโมง ถ้าดึงไม่สำเร็จจะเก็บข้อมูลเดิมไว้ เมนูที่กรอกเองไม่ถูกทับ
- ร้านที่ไม่มีลิงก์และไม่ใช่เชนที่รู้จัก จะขอให้ใส่ลิงก์ ระบบไม่ใช้เครื่องมือค้นหาและไม่เดาเมนู
- วัตถุดิบดึงจากคำในชื่อ/คำอธิบาย จึงยังไม่ใช่ฉลากครบถ้วน

## ธาตุที่ดีที่สุดตอนนี้ (best-now.js)
ให้คะแนนทั้ง 5 ธาตุสำหรับยามปัจจุบันด้วยกติกาเดียวกับการจัดอันดับเมนู แสดงเหตุผลของแต้ม เมนูที่เข้ากัน (จากร้านประจำและไอเดียเมนู) เวลาที่จะเปลี่ยนยาม และธาตุที่ดีที่สุดของทั้ง 12 ยามในวันนี้

## ไฟล์
- index.html, style.css, app.js, mix-core.js, favorites.js, lunar.js — จากไฟล์ต้นฉบับที่คุณส่งมา (แก้ app.js ให้ใช้รูปในเครื่อง)
- api-shim.js — ใช้ server.py ถ้ามี ถ้าไม่มีจะเก็บร้านประจำใน localStorage แทน
- server.py — เซิร์ฟเวอร์และระบบค้นเมนูอัตโนมัติ
- best-now.js — ส่วน "ธาตุที่ดีที่สุดตอนนี้"
- img/ — รูปประกอบ

## ที่ต่างจากเว็บเดิม
- โหมดไม่มีเซิร์ฟเวอร์: ร้าน 7-11 ใช้ภาพรวมแค็ตตาล็อกใน `seven-eleven-catalog.js` อัปเดตไฟล์นี้ด้วย `python3 server.py --snapshot-7eleven seven-eleven-catalog.js` ร้านอื่นต้องใส่เมนูเอง
- ร้านประจำไม่ซิงก์ข้ามอุปกรณ์ เพราะเก็บในเบราว์เซอร์นี้เท่านั้น
- แก้บั๊กใน HTML ที่บันทึกมา: ตัวเลือก "หลีกเลี่ยงถั่วเหลือง" และ "ไม้" ในโปรไฟล์ไม่มีแท็ก <option>
- ไม่มีวันเกิดเริ่มต้น: ผู้ใช้ใหม่เห็น "โปรไฟล์ตัวอย่าง" จนกว่าจะกรอกวันเกิดในโปรไฟล์
